# @fabric-kit/layout

A complete application frame: `FabricAppShell` with a collapsible sidebar, top bar, banner, footer and notification drawer.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/layout @mui/material @emotion/react @emotion/styled
```

```tsx
import { FabricAppShell } from "@fabric-kit/layout";
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/?path=/docs/kits-layout-overview--docs](https://ahmedbilal5.github.io/fabric/docs/?path=/docs/kits-layout-overview--docs)
