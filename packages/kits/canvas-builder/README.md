# @fabric-kit/canvas-builder

A node-based workflow canvas on React Flow: nodes, edges, handles, toolbars, a node palette and validation.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/canvas-builder @xyflow/react react-dnd react-dnd-html5-backend @mui/material @emotion/react @emotion/styled
```

```tsx
import { FabricCanvasBuilder } from "@fabric-kit/canvas-builder";
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/?path=/docs/kits-canvas-builder-fabriccanvasbuilder-overview--docs](https://ahmedbilal5.github.io/fabric/docs/?path=/docs/kits-canvas-builder-fabriccanvasbuilder-overview--docs)
