# @fabric-kit/versioning

A version history drawer: published versions and autosaves on a timeline, with preview, rename, restore, duplicate and delete. Works with any backend.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/versioning @mui/material @mui/lab @emotion/react @emotion/styled
```

```tsx
import { FabricVersionHistoryDrawer } from "@fabric-kit/versioning";
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/?path=/docs/kits-versioning-overview--docs](https://ahmedbilal5.github.io/fabric/docs/?path=/docs/kits-versioning-overview--docs)
