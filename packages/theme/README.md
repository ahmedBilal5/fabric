# @fabric-kit/theme

Fabric's MUI theme with light and dark color schemes, `DesignSystemProvider`, `createFabricTheme` for your own brand, and color-mode hooks.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/theme @mui/material @emotion/react @emotion/styled
```

```tsx
import { DesignSystemProvider } from "@fabric-kit/theme";

<DesignSystemProvider>
  <App />
</DesignSystemProvider>;
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/?path=/docs/foundations-theming--docs](https://ahmedbilal5.github.io/fabric/docs/?path=/docs/foundations-theming--docs)
