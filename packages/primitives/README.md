# @fabric-kit/primitives

Layout and text primitives for Fabric apps: `FabricFlex`, `FabricStack`, `FabricInline`, `FabricGrid`, `FabricText` and `FabricSurface`.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/primitives @mui/material @emotion/react @emotion/styled
```

```tsx
import { FabricStack, FabricText } from "@fabric-kit/primitives";

<FabricStack gap="md">
  <FabricText textVariant="headingSm">Billing</FabricText>
</FabricStack>;
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/](https://ahmedbilal5.github.io/fabric/docs/)
