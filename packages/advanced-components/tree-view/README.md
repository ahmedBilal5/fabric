# @fabric-kit/tree-view

The free MUI X Tree View with Fabric styling.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/tree-view @mui/x-tree-view @mui/material @emotion/react @emotion/styled
```

```tsx
import { FabricTreeView } from "@fabric-kit/tree-view";
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/](https://ahmedbilal5.github.io/fabric/docs/)
