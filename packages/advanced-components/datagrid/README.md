# @fabric-kit/datagrid

The free, MIT-licensed MUI X Data Grid with Fabric styling. Re-exports the whole `@mui/x-data-grid` API.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/datagrid @mui/x-data-grid @mui/material @emotion/react @emotion/styled
```

```tsx
import { FabricDatagrid } from "@fabric-kit/datagrid";

<FabricDatagrid rows={rows} columns={columns} />;
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/](https://ahmedbilal5.github.io/fabric/docs/)
