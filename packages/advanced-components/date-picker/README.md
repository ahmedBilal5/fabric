# @fabric-kit/date-picker

Date, time, date-time and date-range pickers built on the free MUI X pickers, with the localization provider built in. Values are plain `Date`s.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/date-picker @mui/x-date-pickers @mui/material @emotion/react @emotion/styled
```

```tsx
import { FabricDatePicker } from "@fabric-kit/date-picker";

<FabricDatePicker label="Due date" value={date} onChange={setDate} />;
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/](https://ahmedbilal5.github.io/fabric/docs/)
