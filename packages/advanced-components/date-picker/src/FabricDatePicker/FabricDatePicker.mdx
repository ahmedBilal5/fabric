# FabricDatePicker

Design-system date picker. Wraps MUI X `<DatePicker>` with `LocalizationProvider` + `AdapterDayjs` baked in, so consumers don't need to install dayjs or wrap the tree in a provider. `value` accepts a native `Date`, a `Dayjs`, an ISO string, or `null`; `onChange` always fires with a plain `Date | null`.

**Use it for:**
- Effective-from / valid-until fields on rules, quotes, and workflows
- Filter-bar single-date selection
- Form fields where the user picks a single calendar date (no time-of-day)

**Do not use for:** date + time selection (compose MUI X `<DateTimePicker>`) · date ranges (compose two pickers or MUI X `<DateRangePicker>` from Pro) · relative offsets ("in 2 weeks") — use plain `<FabricTextField>` with helper text.

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricDatePicker/index.tsx) · [MUI X DatePicker docs](https://mui.com/x/react-date-pickers/date-picker/)

## Accessibility

- Label + input linked via `useId()` (`aria-labelledby`)
- Helper text linked via `aria-describedby` (`useId()`)
- Error state uses `aria-invalid` (via MUI's `error` prop) — announced by screen readers
- Calendar popover is a `role="dialog"` (MUI X built-in) with focus trap and Escape-to-close
- Keyboard: `←`/`→` day, `↑`/`↓` week, `Page Up`/`Page Down` month, `Shift+Page Up`/`Page Down` year
