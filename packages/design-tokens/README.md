# @fabric-kit/design-tokens

Fabric's design tokens: color, typography, spacing, radii, shadows, motion and z-index as plain TypeScript values, with a dark-scheme set.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/design-tokens
```

```tsx
import { spacing, radii, status } from "@fabric-kit/design-tokens";
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/?path=/docs/foundations-design-tokens-overview--docs](https://ahmedbilal5.github.io/fabric/docs/?path=/docs/foundations-design-tokens-overview--docs)
