# FabricPagination

The Pagination component enables the user to select a specific page from a range of pages. `FabricPagination` wraps MUI `TablePagination` with a sliding-window page-number display, a rows-per-page dropdown, and a "from – to of count" label. Use it under card grids and custom lists. (`FabricDatagrid` has its own built-in pagination.)

**Use it in:**
- Card-view listings (data models, smart views, data objects, rules, templates)
- Any grid/table that needs client-side or server-side pagination controls
- Toolbars below data grids

**Do not use for:** infinite scroll · cursor-based pagination · "load more" buttons · URL-based page navigation (use MUI `Pagination` instead).

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricPagination/index.tsx) · [MUI TablePagination](https://mui.com/material-ui/react-pagination/#table-pagination) · [MUI Pagination](https://mui.com/material-ui/react-pagination/)

## Basic usage

Pass `count`, `page`, `rowsPerPage`, `onPageChange`, and `onRowsPerPageChange`. The component handles page recalculation when rows-per-page changes.

## Accessibility

- The component uses MUI `TablePagination` which renders proper ARIA attributes on navigation buttons.
- Page buttons have accessible labels ("go to page 1", "go to previous page", etc.).
- The rows-per-page dropdown is a native `<select>` for maximum screen-reader compatibility.
- **Keyboard:** Tab navigates between controls (select, page buttons, prev/next). Enter/Space activates.
