# FabricStepper

Steppers convey progress through a sequence of steps. `FabricStepper` is a data-driven wrapper over MUI `Stepper`: pass a `steps` array instead of composing `<Step>` / `<StepLabel>` / `<StepContent>` by hand.

**Use it in:**
- Multi-step wizards (account setup, template creation, checkout, imports)
- Approval chains and workflow rails
- Onboarding flows

**Do not use for:** progress bars (use [FabricCircularProgress](?path=/docs/components-fabriccircularprogress--overview) or `LinearProgress`) · breadcrumbs (use [FabricBreadcrumbs](?path=/docs/components-fabricbreadcrumbs--overview)) · tabs (use [FabricTabs](?path=/docs/components-fabrictabs--overview)).

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricStepper/index.tsx) · [MUI Stepper](https://mui.com/material-ui/react-stepper/) · [WAI-ARIA step pattern](https://www.w3.org/WAI/ARIA/apg/patterns/stepper/) (informal)

## Basic usage

Pass a `steps` array with a `label` per item and set `activeStep`. The current step shows a blue dot, completed steps a green check, and steps not reached yet a grey dot. Horizontal steppers put each label under its icon; pass `alternativeLabel={false}` to put labels beside the icons.

## Accessibility

- MUI Stepper does not implement the WAI-ARIA "process" pattern out of the box; the root is a `<div>`. If your stepper is the primary progress indicator of the page, wrap it in `<nav aria-label="Progress">` and consider `role="list"` on the root.
- `StepButton` (used when `onStepClick` is set) is a real `<button>` — Enter/Space activate.
- Error and disabled states are conveyed visually only. Pair `error` with an accessible label change (e.g. put "(error)" in the label ReactNode) if the audience relies on screen readers.
