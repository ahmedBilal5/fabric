# FabricListItemSimple

Lists present information in a concise, easy-to-follow format through a continuous, vertical index of text or images. `FabricListItemSimple` is a single-select sidebar list built on MUI `ListItemButton` for settings pages and similar sub-navigation.

**Use it in:**
- Settings sidebars with click-to-select navigation
- Vertical nav lists with icon + label items
- Permission panels, data-model panels, rule settings, schema layouts

**Do not use for:** drag-reorderable lists (use DnD primitives) · data grids · tab strips (use [FabricTabs](?path=/docs/components-fabrictabs--overview)) · multi-select lists.

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricListItemSimple/index.tsx) · [MUI List](https://mui.com/material-ui/react-list/) · [WAI-ARIA listbox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)

## Settings list

A lighter settings list has no lines between options and rounded (4px) hover / selected rows. Set both through `sx`:

```tsx
sx={{
  "& .MuiDivider-root": { display: "none" },
  "& .MuiListItemButton-root": { borderRadius: `${radii.md}px` },
}}
```

## Accessibility

- The root `<List>` receives `role="listbox"` with the `aria-label` you provide.
- Each item uses MUI `ListItemButton` which handles `aria-selected`, focus management, and keyboard interaction.
- **Keyboard:** Tab focuses the list, Arrow Up/Down moves between items, Enter/Space selects.
