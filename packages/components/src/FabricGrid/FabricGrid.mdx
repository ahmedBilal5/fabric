# FabricGrid

Responsive 12-column layout — the design-system pass-through for MUI v9 `Grid` (the CSS Grid-based successor to `Grid2`). Every prop passes through unchanged.

**Use it for:**

- Two-column dialog form layouts (name / value, key / description)
- Responsive card grids (4-across on desktop, 2-across on tablet, 1-across on mobile)
- Sidebar-plus-main compositions (`size={{ xs: 12, md: 4 }}` + `size={{ xs: 12, md: 8 }}`)
- Any layout that needs breakpoint-aware column sizing beyond what `Flex` / `Inline` / `Stack` primitives cover

**Prefer primitives when possible:**

- Fixed row of items with equal gap → `Inline gap="md"`
- Single-column stack of items → `Stack gap="md"`
- Simple two-thirds / one-third split → `Flex` with `flexBasis` on children

Reach for `FabricGrid` when breakpoint-responsive column arithmetic (`size={{ xs, sm, md, lg, xl }}`) actually earns its cost.

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricGrid/index.tsx) · [MUI v9 Grid docs](https://mui.com/material-ui/react-grid/)

## Responsive breakpoints

The `size` prop accepts a responsive object: `size={{ xs, sm, md, lg, xl }}`. Coming from MUI v5's `<Grid item xs={12} sm={6}>`? Write `<FabricGrid size={{ xs: 12, sm: 6 }}>`.
