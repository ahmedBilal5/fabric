# FabricDialog

Modal dialogs inform users about a task, require decisions, or involve multiple form fields inside a temporary surface. Use it for "Are you sure?" prompts, short creation forms and confirm-deletion flows. Extends MUI `Dialog`, adds a data-driven `actions` API, first-class `title` / `subtitle` / `titleIcon` slots, and an optional `confirmDelete` mode gated behind typing "DELETE".

**Use it for:**
- Confirm-before-destructive-action prompts (delete workspace, discard changes)
- Multi-field creation forms (New workspace, New rule, New tag)
- Detail viewers (Record details, Version history)
- Any modal decision the user must acknowledge before continuing

**Do not use for:** transient success/error toasts — use [FabricSnackbar](?path=/docs/components-fabricsnackbar--overview). For inline warnings that don't block flow, use MUI `Alert`.

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricDialog/FabricDialog.tsx) · [WAI-ARIA dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) · [Material Design guidance](https://m2.material.io/components/dialogs)

## Basic dialog

`open` + `onClose` control visibility. `title` renders in the header, `actions` become footer buttons — each entry accepts the full `FabricButtonProps` surface (loading, tooltip, menu, `data-cy`).

## With title icon

`titleIcon` accepts any `ReactNode` — an icon, an inline badge, or a small `<Chip>`. Renders inline before the title text. Add `titleIconTone="info"` or `"attention"` to wrap an (uncoloured) icon in a 36px tinted circle.

## Message dialogs

The default look: an 8px panel with the panel shadow, 24/32 Medium capitalised title, a 32px bordered close button in the title row, 24px body padding and a 16/24 footer. The theme (`MuiDialog*` overrides) owns the panel, title, body and footer; `FabricDialog` owns the close button and the tinted icon circle. Width is left to the consumer — the stories use `dialogWidth.md`.

## Limitations

### `confirmDelete` matches by label OR color

The delete-detection heuristic gates an action if `label === "delete"` (case-insensitive, trimmed) OR `color === "error"`. If your destructive action is neither ("Remove", "Archive", "Erase"), rename it or set `color="error"`. Custom detection isn't currently supported.

### `dividers` adds two dividers

`dividers` draws a line above the content and another above the actions. If you want only the top divider, drop `dividers` and add a `<Divider />` manually.

### Aria-labelling requires either `title` or explicit `aria-label`

`useId()`-generated `aria-labelledby` points at the title text. If you pass a completely custom header (via `content` or `children`), also pass `aria-labelledby={yourId}` or the modal will lack a name.
