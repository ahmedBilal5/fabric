# FabricAutocomplete

The autocomplete is a normal text input enhanced by a panel of suggested options. `FabricAutocomplete` wraps MUI `Autocomplete` with a `FabricTextField`-based default input — top-level `label`, `placeholder`, `error`, and `helperText` handle the 90% case, so consumers no longer hand-roll a 15-line `renderInput` for every field.

**Use it in:**
- Entity pickers (user, company, group, tag, workspace)
- Filter combos ("filter by status", "filter by assignee")
- Type-ahead search inside dropdowns
- Create-new patterns (free solo)
- Any place where a `<FabricSelect>` list would exceed ~10 options

**Do not use for:** short mutually-exclusive lists ≤ 5 options (use [FabricSelect](?path=/docs/components-fabricselect--overview) or [FabricToggleButtonGroup](?path=/docs/components-fabrictogglebuttongroup--overview)) · yes/no toggles (use [FabricSwitch](?path=/docs/components-fabricswitch--overview)) · async server search with a custom result panel — those want a bespoke component.

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricAutocomplete/index.tsx) · [WAI-ARIA combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) · [MUI Autocomplete](https://mui.com/material-ui/react-autocomplete/)

## Accessibility

- Autocomplete implements the [WAI-ARIA combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) — provide a `label` (or `aria-label` on the input) so screen readers announce the field.
- **Keyboard:**
  - `↑` / `↓` — move focus through options
  - `Enter` — select the focused option
  - `Esc` — close the popover (twice = clear the value)
  - `Home` / `End` — jump to first / last option
  - `Backspace` — remove the last chip in multi mode
- The listbox announces "X results available" as the user types.
- In multi mode, each chip is a focusable button with an accessible delete label.
