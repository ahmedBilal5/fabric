# FabricChip

Compact elements that represent an input, attribute, or action. Filter tokens, status tags, permission badges, and category labels all render through `FabricChip`. Extends MUI `Chip` verbatim — every prop, every variant, every callback is preserved.

**Use it for:**
- Filter tokens in search bars ("Status: Active" · "Owner: Me")
- Removable input tags (email recipients, keyword lists)
- Status / severity indicators (Draft, Published, Error)
- Category / permission labels on cards and rows

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricChip/index.tsx) · [Material Design guidance](https://m2.material.io/components/chips)

## Variants, colors and sizes

- `variant="filled" | "outlined" | "filledAlt"`.
- `color`: `default`, `queued`, `running`, `success`, `warning`, `cancelled`, `error`, `suspended`, `archived`, `unknown`. `primary`, `secondary` and `info` keep MUI's styling.
- `size="small" | "medium"`: 18px and 26px high.
- `disabled` uses muted colors (the last chip in each row).

## Limitations

### `size="medium"` height doesn't scale with content

MUI's chip is a fixed pill. If you need a chip that wraps to multiple lines, apply `sx={{ height: 'auto', '& .MuiChip-label': { whiteSpace: 'normal' } }}` — Fabric doesn't bake this in because 99% of chips are single-line.

### `onDelete` fires independently of `onClick`

The delete icon has its own click target — the parent chip's `onClick` won't fire when the user clicks the X. Handle deletion in `onDelete` only.

### Focus visibility on outlined chips

The outlined variant has a lower-contrast focus ring than the filled variant on dark backgrounds. If you're rendering chips on `surface.tertiary` or dark mode, verify focus visibility manually.
