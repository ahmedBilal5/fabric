# FabricBreadcrumbs

Breadcrumbs consist of a list of links that help a user visualize a page's location within the hierarchical structure of a website, and allow navigation up to any of its ancestors. `FabricBreadcrumbs` wraps MUI `Breadcrumbs` with a data-driven `items` array — the last item auto-renders as the current-page indicator (bold, non-link) so consumers stop hand-rolling a `map + last-item-special-case` at every detail page.

**Use it in:**
- Detail-page headers (product, template, data-object, workflow)
- Wizard progress trails
- Nested folder / tree navigation
- Any view where the user needs to jump back up the hierarchy

**Do not use for:** primary navigation (use a sidebar or top nav) · tab switching (use [FabricTabs](?path=/docs/components-fabrictabs--overview)) · stepper progress in a single-page wizard (use a stepper).

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricBreadcrumbs/index.tsx) · [WAI-ARIA breadcrumb pattern](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/) · [MUI Breadcrumbs](https://mui.com/material-ui/react-breadcrumbs/)

Pass an `items` array of `{ label, href }`. The last item automatically renders as the current page (bold, non-link, with `aria-current="page"`).

## Accessibility

- The root `<nav>` element is labelled via `aria-label="breadcrumb"` (MUI default).
- The current-page item is marked `aria-current="page"` so screen readers announce it correctly.
- Non-current items render as `<a>` elements and are keyboard-focusable in order.
- Icons in items should be decorative — the label carries the accessible text.
