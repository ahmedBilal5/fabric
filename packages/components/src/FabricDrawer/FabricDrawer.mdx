# FabricDrawer

Navigation drawers provide ergonomic access to destinations in a site or app functionality such as switching accounts. Extends MUI `Drawer` with `anchor` defaulting to `"right"`.

**Use it in:**
- Filter panels (right-anchored, non-modal)
- Settings / detail side-sheets
- Function-list panels in data-flow editors
- Preview drawers (bottom-anchored)

**Do not use for:** dialogs requiring confirmation (use [FabricDialog](?path=/docs/components-fabricdialog--overview)) · permanent app-shell sidebars (use styled MUI Drawer directly).

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricDrawer/index.tsx) · [MUI Drawer](https://mui.com/material-ui/react-drawer/) · [Material Design navigation drawer](https://m2.material.io/components/navigation-drawer)

## Temporary drawer

Temporary navigation drawers can toggle open or closed. Closed by default, the drawer opens temporarily above all other content until a section is selected. The Drawer can be cancelled by clicking the overlay or pressing Escape.

## Anchor

Use the `anchor` prop to specify which side of the screen the Drawer originates from. The default is `"right"`, the usual place for detail and filter panels. Use `"bottom"` for preview and query-builder panels.

## Persistent drawer (non-modal panel)

The most common pattern in the codebase — a persistent side panel that doesn't block interaction with the main content. Use `variant="persistent"` with relative positioning.

## Accessibility

- The drawer renders as a MUI `Modal` in temporary mode — focus is trapped inside and restored on close.
- Pressing Escape closes the drawer (via `onClose` with `reason: 'escapeKeyDown'`).
- Persistent drawers don't trap focus — they coexist with page content.

---

## API

Extends `DrawerProps` from MUI directly. No custom props beyond `anchor` defaulting to `"right"`.
