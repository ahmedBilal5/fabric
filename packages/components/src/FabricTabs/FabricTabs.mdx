# FabricTabs

Tabs make it easy to explore and switch between different views. They organize and allow navigation between groups of content that are related and at the same level of hierarchy. Extends MUI `Tabs` with a declarative `tabs` array.

**Use it in:**
- Filter drawers with "Saved" / "Shared" / "All" tab strips
- Workspace layouts with feature tab headers (dataManager, dataModel, dataObject)
- Node-settings modals with config tab strips (Workflow builder)
- Any view with 2–12 switchable sections

**Do not use for:** navigation bars (use a router-linked nav) · accordion sections (use [FabricAccordion](?path=/docs/components-fabricaccordion--overview)) · single-toggle views (use [FabricSwitch](?path=/docs/components-fabricswitch--overview)) · pagination (use [FabricPagination](?path=/docs/components-fabricpagination--overview)).

**Quick links:** [Source](https://github.com/ahmedBilal5/fabric/blob/main/packages/components/src/FabricTabs/index.tsx) · [WAI-ARIA tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) · [MUI Tabs](https://mui.com/material-ui/react-tabs/) · [Material Design tabs](https://m2.material.io/components/tabs)

## Accessibility

- Label `Tabs` via `aria-label` or `aria-labelledby`. Name the strip for what it switches, e.g. `aria-label="Project sections"`.
- **Keyboard:** Arrow keys move focus between tabs. Enter/Space selects. Home/End jump to first/last tab.
- By default, tabs use "manual activation" — focus moves independently of selection. Pass `selectionFollowsFocus` if selection should follow focus automatically.
