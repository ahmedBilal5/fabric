# FabricStatus

A colored dot with a short label for the state of a record, job or service: "Active", "Failed", "Deploying".

**Use it for:** status columns in tables, list rows, page headers and detail panels, wherever several statuses sit side by side.

**Use `FabricTag` instead** when the status needs more weight, for example a single status badge next to a page title.

```tsx
<FabricStatus status="success" label="Active" />
<FabricStatus status="running" label="Deploying" pulse />
```

The colors are the theme's semantic palette, the same ones `FabricTag` and `FabricChip` use, so they follow dark mode and any brand overrides.

## Dot only

Where space is tight, drop the label and pass `aria-label`; the dot is then announced as an image with that name. Consider a tooltip so sighted users can read it too.

## Long labels

Labels wrap; the dot stays aligned with the first line.

<Canvas of={StatusStories.LongLabel} />

## Accessibility

- Color is never the only signal: always show a label, or give a dot-only status an `aria-label`.
- The dot is hidden from screen readers when a label is present.
- The pulse animation respects `prefers-reduced-motion`.

## Relation to MUI

MUI has no status component; `FabricStatus` is a plain `<span>` styled with theme variables. It accepts `sx`, `className`, a ref and any span attribute.
