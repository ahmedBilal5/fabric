# FabricIconButton

An icon-only button. `FabricIconButton` wraps MUI `IconButton` with Fabric's button look at a fixed 26px square. It sits next to [FabricButton](?path=/docs/components-fabricbutton--overview) and takes the same `variant` and `shape` props.

**Props added to MUI `IconButton`:**
- `variant`: `text` (default), `outlined` or `contained`.
- `shape`: `standard` (4px corners, default) or `round` (24px corners, a circle at 26px).
- `color`: `primary` (default), or `error`, `info`, `success`, `warning`. The semantic colors reuse the semantic `FabricButton` states (for example a red delete button).
- `aria-label`: **required**. An icon-only control has no visible name, so screen readers need one.

Both MUI `size` values render at 26px. The icon slot is 18px in the `round` shape and 16px in the `standard` one. The `outlined` variant has a grey stroke that darkens on hover; the icon turns blue. The rest of the MUI `IconButton` surface (`disabled`, `href`, `component`, handlers, `sx`) is unchanged. The MUI `color` prop is not accepted; colors follow the button states.

**Use it for:** toolbar actions, close / delete / edit buttons, and menu triggers that show only an icon.

**Do not use for:** actions with a text label (use [FabricButton](?path=/docs/components-fabricbutton--overview)).

## Accessibility

- `aria-label` is required, since the button has no visible name.
- It is a native `button`: Tab focuses it, and Enter and Space activate it.
- At 26px the touch target is small. For touch-first screens, set a larger `width` and `height` in `sx`.
