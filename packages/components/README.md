# @fabric-kit/components

MUI components with Fabric's defaults and extra props: loading buttons with menus, data-driven selects, dialogs with actions, tags, status chips and more. Every MUI prop still works.

Part of [Fabric](https://ahmedbilal5.github.io/fabric/), a free, open-source design system on top of MUI.

```bash
pnpm add @fabric-kit/components @mui/material @mui/lab @mui/x-date-pickers @emotion/react @emotion/styled
```

```tsx
import { FabricButton } from "@fabric-kit/components";

<FabricButton variant="contained" loading={saving}>
  Save
</FabricButton>;
```

Documentation: [https://ahmedbilal5.github.io/fabric/docs/](https://ahmedbilal5.github.io/fabric/docs/)
