# @fabric-kit/icons

3,300+ [Material Symbols](https://fonts.google.com/icons) (Rounded, weight 300, 24px grid) as tree-shakeable React components. Each icon is an MUI `SvgIcon`, so it works exactly like `@mui/icons-material`, and every `@mui/icons-material` name is available too.

```bash
pnpm add @fabric-kit/icons @mui/material @emotion/react @emotion/styled
```

## Usage

Import each icon from its own path:

```tsx
import Bookmark from "@fabric-kit/icons/Bookmark";
import Description from "@fabric-kit/icons/Description";

<Bookmark />
<Description fontSize="small" color="primary" />
<Description sx={{ fontSize: 40 }} htmlColor="#7B1FA2" />
```

- Names are PascalCase versions of the Material Symbols names (`bookmark` → `Bookmark`, `3d_rotation` → `ThreeDRotation`).
- Props: `fontSize` (`small` 20px / `medium` 24px / `large` 35px / `inherit`), `color` (theme color), `htmlColor`, `sx`, plus all `SvgIcon` props.
- Only the icons you import are bundled (about 0.4 KB gzipped each).
- Every `@mui/icons-material/<Name>` path also exists as `@fabric-kit/icons/<Name>`. When a Fabric icon has the same name, the Fabric (weight 300) version wins.

Browse and search every icon in the docs: **Foundations → Icons**.

## Add an icon

1. Put a 24×24 SVG in `svg/<snake_name>.svg` with no fill colors.
2. Add the name to a category in `icons.manifest.json`.
3. Run `pnpm --filter @fabric-kit/icons build`.

`dist/` is generated by `scripts/generate.mjs`. Build it before running Storybook or typechecking packages that use icons.
