New package: `@fabric-kit/hooks`. React hooks (`useDisclosure`, `useDebounce`, `useDebouncedCallback`, `useHotkeys`, `useClipboard`, `useLocalStorage`, `useRelativeTime`) and `Intl`-based formatting helpers (`formatDate`, `formatRelativeTime`, `formatNumber`, `formatCurrency`, `formatPercent`, `formatFileSize`). Depends only on React.
