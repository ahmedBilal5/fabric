New package: `@fabric-kit/patterns`, for whole pages built from Fabric components and kits. It starts with `FabricSystemPage`: not-found (404), forbidden (403), no-access, server-error (500) and maintenance pages with default copy and actions (go home, go back, try again, request access), an error reference line, and full-viewport or in-container layout.
