# Code of Conduct

Fabric follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests, discussions or any other project space.

To report a problem privately, contact the maintainer through their GitHub profile ([@ahmedBilal5](https://github.com/ahmedBilal5)). Reports are handled confidentially.
